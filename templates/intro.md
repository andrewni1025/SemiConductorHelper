> 这是 **入门地图（intro）** 的内容模板。复制本文件到 `src/content/intro/` 下，重命名后修改 frontmatter 与正文。

## Frontmatter 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 文章标题 |
| `description` | 否 | 一句话简介 |
| `order` | 否 | 排序权重，数字越小越靠前 |
| `tags` | 否 | 标签数组 |
| `updated` | 否 | 更新日期，建议每次修改后更新 |

## 写作风格

- 写给 **完全外行的朋友**：用类比、举例、最少术语
- 一篇控制在 **800-2000 字**，不要太长
- 关键概念第一次出现时给出英文，例如：晶圆代工（Foundry）
- 多用列表、表格、信息图组件，少写大段说明
